# Investect website

A free static website ready for GitHub Pages.

## Publish on GitHub Pages
1. Create a new public GitHub repository (for example `investect`).
2. Upload `index.html`, `style.css` and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide the live Pages address. You can then add `investect.com` under **Custom domain** and point your DNS to GitHub Pages.

## Before launch
Replace every `href="#"` placeholder with your real YouTube, TikTok, Discord, X and waitlist/course links. Add your privacy, terms, risk disclosure and affiliate disclosure pages before monetising.
